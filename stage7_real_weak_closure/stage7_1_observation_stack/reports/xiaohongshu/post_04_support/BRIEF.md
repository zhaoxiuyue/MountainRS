## 一、四张卡

只做 4 张。**封面必须大字吸睛，后面三张可以干**。

### 01 封面 —— 唯一任务是让人想点进来

主视觉：**超大数字 `21`**，占据画面上半部，配一行大字 **「一景没挑」**。

下方一行钩子（字号次于主视觉但仍要显眼）：

> 其中 3 景，我导之前就知道不合格。

**排版要求**：
- `21` 要做到真正的大——建议占画面高度 1/3 以上，是全篇最大的字；
- 封面**只放这三样**：主数字、「一景没挑」、钩子句。标题与副标题可用小字压在顶部或底部，不要抢主视觉；
- 不要在封面塞漏斗、表格、代码或任何数据块——那些全部后移；
- 张力来源是反常识：**明知没用还全做**，读者会想知道为什么。

### 02 规矩 —— 为什么我不能挑

要说清两件事的**时间顺序**：

- 选景协议状态：`frozen before any Stage 7.1 GEE catalog query`
- 目标网格：`The choice is fixed before any new acquisition catalog is viewed`（冻结日 2026-07-23）

即**标准冻结在看见任何一景之前**，不是"下载完再定标准"。

再放导出集条款（可引原文片段）：

> 禁止任何 cloud / QA / residual / fit / validation / test / model 准则移除、替换或重排导出集成员；`CLOUD_COVER` 不得用于 top-N 或排序。

一句话收：**所以那 3 景我明知不合格，也必须一景不落地导完。**

### 03 漏斗 —— 唯一允许淘汰的那一层

```
候选宇宙（identity hash 冻结）   21
成功获取                        21
身份与语义完整                   21
精确网格通过                     21
stack_eligible                  18   ← 只有这一层收窄
数据集划分        train 10 / validation 3 / test 5
```

**关键视觉决策**：这个漏斗几乎不收窄。**不要假装它层层变窄**——把前四层画成**等宽直筒**，只在 `stack_eligible` 那一层收一次，旁边标注：

> 只有一处允许淘汰，它在这里。

"不收窄"本身就是结论：筛选只发生在预注册标准那一层，其余各层不淘汰任何成员。这比画一个假漏斗诚实，也更有记忆点。

### 04 代价与拷问

那 3 景是谁、为什么：

| 日期 | QA-clear 像元 |
|---|---|
| 2023-02-02 | 0 |
| 2023-06-10 | 0 |
| 2023-07-12 | 0 |

冬雪与雨季，整景没有一个 QA-clear 像元。**不是"我嫌它质量差"，是预注册标准判它没有可用观测。**

结尾问题（本篇落点，要给足空间）：

> 剔除低质量影像，什么时候是在去噪，什么时候是在删掉最难的真实世界？

可加一句回扣第一篇的暗线：**最难的像元恰恰是背阴坡**——删掉难的，等于删掉你要研究的对象。
