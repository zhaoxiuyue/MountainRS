## 3. 证据栈的形式

本节点产出的是**不可变 manifest，不是本地数据副本**。依据三条：合同 passCriteria 8 的原话就是「发布不可变 dataset/domain/split manifest」；架构 v3.3 §2.2 明确永久保留的对象是证据身份与可追溯性，不必然是本地热存储字节；Stage 7.6 的外扩 DEM 已确立先例。

manifest 的 ROI 与 acquisition_source 字段足以重建全部数据，验证方法（同参数重取比对 sha256）已在 Stage 7.6 的 DEM 上实测通过。**但本节点未生成 30 m 证据栈字节，故该验证尚未对本节点数据执行**——这是 manifest 形式的已知代价，如实登记。

## 4. Reference Registry

**Sentinel-2（`COPERNICUS/S2_SR_HARMONIZED`）判 `reference_observation`，通过独立性 I1–I4 与泄漏审计 L1–L4 全部检查。** 五域 ±3 天 tight 匹配共 **603 对**。

**I3 是山地遥感特有的一条**：参考产品是否做过地形校正必须登记。本项目要检验的正是地形对辐射的调制，任何做过地形校正的参考都携带一个未经本项目验证的地形假设——用它验证我们的地形处理，等于用一个未验证的假设验证另一个；两者若犯同向错误，一致性会很好看而两者同时是错的。

S2 判 `preferred`（未做地形校正），但**证据强度已如实标注**：依据是公开处理文档加上元数据中相关字段的缺失（76 个属性无 terrain / DEM / slope），**不是产品元数据的肯定性声明**。字段缺失不等于否定。若后续发现相反证据，本条目须重新分级，其已产出的一致性结论一并受影响。

可验证与不可验证范围分开登记：**可**验跨传感器反射率一致性、地形调制在两套独立观测中的表现；**不可**验绝对辐射定标（两者定标链虽独立但均未经本项目校验），**不可**验 DEM 几何本身（参考不含地形处理，对该问题无信息）。

跨传感器比较须携带光谱差异限定——S2 的 B4/B8A 与 Landsat 的 SR_B4/SR_B5 中心波长与带宽不同，不得当作同一量直接相减。

**地面测量判 `unavailable`**，并登记了检索过程、已识别但未获取的来源（BSRN 需注册且站址重合未核实、ChinaFLUX/CERN 不公开）与恢复条件。协议要求区分「未检索」与「不可得」——混同会使「独立参考不足」这一结论失去可核查性。

## 5. 重新资格化 Gate：一个推翻默认假设的结果

判定 `requalification_not_warranted`，三类判据全部不满足。**Stage 7.6 的负结果与 Stage 7.7 的空集保持不变。**

### G1 的同尺度对照

| | domain 级 v_sky IQR |
|---|---|
| **基准 D0 岷山** | **0.0762** |
| 太白山秦岭 | 0.0849 |
| 高黎贡山 | 0.0665 |
| 祁连山中段 | 0.0655 |
| 阿尔泰山中段 | 0.0550 |
| 天山中段 | **0.0069** |

**五个断裂域中只有一个的地形遮挡变化范围超过基准。**

这直接冲击了 Stage 7.6 负结果的一个主要备选解释——「单 ROI 的 v_sky 变化不够，换更多域就好了」。跨越 542–2522 km、从干旱到湿润、从草地到常绿阔叶林的五个域，在这个维度上整体并不优于原 ROI。

**它的边界**：这不证明该解释是错的。五个域的选择依据是断裂与可用性，不是 v_sky 变化范围——它们不是为「最大化地形遮挡变化」而挑的样本。但它说明：指望靠换区域自动获得更大的地形遮挡变化，在这批域上没有实现。

**附带暴露 A5 的一个局限**：天山高差 1415 m 稳过门槛，但 v_sky 中位 0.9962、IQR 0.0069——地形开阔，几乎无遮挡。**高差达标不蕴含地形遮挡有变化。** 该局限在准入阶段不可见（v_sky 要到 Gate 阶段才算），按事实登记，不追认为准入条件的缺陷。

### G1 的测量层级问题

冻结判据要求「逐 domain 逐 fold 在其训练支持区内取 IQR」，但本节点不产出 fold 结构（fold 是 Stage 7.3 针对单 ROI 的构造）。本次改测 domain 级，二者关系是**单向**的——fold 训练区是 domain 支持区的子集，子集的 IQR 不大于全集：

- domain 级 < 0.10 ⇒ fold 级必然 < 0.10 ⇒ **可确定判不满足**
- domain 级 ≥ 0.10 ⇒ fold 级未定 ⇒ 不足以判满足

本次测得 0.0655，正落在可确定的那一侧，故判定严格。**不以 domain 级数值冒充判据所要求的 fold 级数值。**

### G2 与 G3

G2 不满足：无 `ground_truth`；Sentinel-2 的 `unverifiable_scope` 明确排除验证绝对定标与 DEM 几何，解除不了 Stage 7.5 的任何 `deferred_missing_anchor`。

G3 不满足：新证据仍是光学观测，都须经由 L2 算子才能连到 L1 状态，而 qualified 算子集合为空——不存在绕开未资格化算子的信息通路。「新域数据更多，或许有助于状态激活」属判据明确排除的笼统表述。

## 6. 一项 post-result 修订与一处实现错误

### A7 的暴露地位

准入条件 **A7（人为改造地表 ≤ 50%）由所有者裁决在核验结果已知后新增**，C6 六盘山黄土区（农田 54.1%）因此出局，C8 阿尔泰递补。

**标记 `post_result`，不声称 preregistered。** 执行手当时推荐维持现状，理由是任何阈值的选择都发生在 54.1% 已知之后；所有者选择新增 A7。裁决权属所有者，标记不因裁决合法而免除——冻结时序约束的是「规则不得在看过结果后改动」，与改动方向无关，允许事后收紧等于允许事后按结果挑选。

污染范围**仅限 A7 及其直接后果**；A1–A6、真断裂判据、确定性排序与替补规则均为结果前冻结，保持 preregistered。

一项相关事实：七个未出局候选的人为改造占比全为 0.0–0.1%，分布极端二分，故 1%–54% 之间的任何阈值都只淘汰 C6。**阈值取值不影响结果**——记录此点以说明该修订的实际影响范围，不用于淡化其暴露标记。

### 一处被自己抓住的实现错误

第三阶段初版用 `ee.Reducer.mode()` 求 IGBP 主导类别，该 reducer 在 reduceRegion 重采样之后对离散类别值失效。基准被判为占比 **1.1%** 的「稀树草原」而真实主导是 **46.1% 的草地**；C6 被判为占比不足 0.6% 的「永久湿地」而真实主导是 **54.1% 的农田**。

据此产出的两项 finding（「MODIS 在高山区不可靠」「C6 主导湿地」）全部撤回。若未被发现，所有者会基于两项虚假事实裁决，且两项都指向「判据不可靠、需修改冻结件」，可能促成一次本不必要的规则修改。

**它被抓住不靠任何自动检查**，而是因为在准备裁决材料时坚持补充可核查的事实底座。修正后强制记录主导类别的**占比**与前五构成——只报类别不报占比，正是这个错误能存活到裁决请求阶段的原因。

修正未改变合格集与选择结果，改变的是断裂依据构成：天山、祁连、念青、阿尔泰实际只有气候断裂，它们与基准同为草地主导。

## 7. 一处环境变更与其验证

当前环境已无 scipy（Stage 7.6 计算 v_sky 时尚有）。本节点未改动环境，而是用 numpy 重写 v_sky 实现，并**以 Stage 7.6 冻结的 v_sky 栅格逐点验证**：max|Δ| = **2.98e-08**，为 float32 存储精度量级。

改依赖不如改实现——且这次改动顺带产出了一个可核查的一致性证据，而不是一句「应该等价」的断言。

## 8. 边界与不可推论

- **`qualified` 只表示证据可用于评估**，不表示模型跨域成功（合同 boundaries）。
- **本节点无 `ground_truth`**，任何结论不得使用真值措辞。
- **相对既有结果为 post-result exploratory**：基准 D0 的 residual 与 Stage 7.6 的判定均已公开，故「以这五个域检验既有结论」这一动作不具预注册地位。新域的 acquisition 集合与支持统计本身不受影响——它们是新观测。
- **不得以像元数量或 acquisition 数量补足独立 domain 数量**。四个 evaluation 域就是四个独立单元，不因某域景多而加权。跨域汇总一律 domain 级宏平均，且必须同时报告 domain 级散布——宏平均掩盖分歧，而分歧正是跨域验证要暴露的东西。
- **不得把少于 3 个合格 domain 包装成跨域验证完成**（本节点为 5 个，该禁令对下游引用仍然适用）。
