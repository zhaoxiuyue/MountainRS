# Stratification 子协议 v1

- **状态：** `frozen`
- **合同依据：** Stage 7.4 条款 2（冻结分层的精确谓词、阈值、边界与互斥/重叠矩阵）
- **建立日期：** 2026-08-09
- **批准：** 所有者于 2026-08-09 批准
- **生命周期：** 在 Stage 7.4 **planned 状态**冻结。激活后不得修订；边界与段数不得因任何结果调整。

## 1. 为什么不叫 safe / transition

Stage 7.4 合同原文要求冻结 `safe`、`transition`、`near-zero`、`self-shadow` 四个分层。
逐份检查上游冻结件后确认：

| 分层 | 上游状态 |
|---|---|
| `self_shadow` | **已定义**：`cos_i ≤ 0`（Stage 7.0 data_gap_report、Stage 7.2 mconf-registry） |
| `near_zero` | **已定义**：`0 < cos_i ≤ 0.1`（同上） |
| `safe` | **从未定义** |
| `transition` | **从未定义** |

`safe` 与 `transition` 在全部上游冻结件中仅出现一次——
`stage7_2_baseline_fit/docs/calibration-contract-v1.md:110` 的一句禁令
「也不得在 safe / transition / near-zero / shadow 等评价分区内分别重拟合」——
属于**提及而非定义**。上游不存在任何把二者与 `cos_i` 阈值绑定的谓词。

### 关键决定：不补一个假的物理分区

`safe`、`transition` 这两个词本身在做**物理断言**（安全区、过渡区）。三项证据表明
当前没有依据支撑这个断言：

**① lit 区间内部无自然分界点。** μ 分布连续、单峰、无断点：

| acquisition | 太阳仰角 | lit 内部 μ 的 p05 → p50 → p95 |
|---|---|---|
| LC08_130038_20230101 | 31.14° | 0.144 → 0.608 → 0.930 |
| LC08_130038_20230930 | 50.99° | 0.201 → 0.670 → 0.986 |
| LC08_130038_20230610 | 68.81° | 0.420 → 0.790 → 0.984 |

**② 同一绝对阈值在不同景上含义不同。** μ ∈ (0.1, 0.3] 这一段占 lit 的份额：
order 1 为 **20.9%**，order 10 仅 **1.4%**。差异主要来自太阳高度角，不是地形风险。

**③ 本节点的执行者已暴露于 Stage 7.3 的 residual。** 即使真诚地取某个圆整阈值，
也无法证明该选择未受已见结果影响。

因此若强行补一个 `safe = cos_i > 0.5` 之类的定义，会得到一个
**看起来 preregistered、实际上任意**的阈值，而 `preregistered` 这个标签会为它背书。
本子协议拒绝这样做。

### 采用的替代：描述性分箱

改为对**模型自变量 μ 的定义域**做均匀切分，命名中性，并显式声明不主张物理含义。
依据是「均匀覆盖 μ 的定义域」——这与是否看过 residual 完全无关，故可正当标为
`preregistered`。

## 2. 分层定义（冻结）

`μ = max(cos_i, 0)`，`cos_i` 由 Stage 7.2 `cos-i-registry-v1.json` 冻结提供。

| stratum_id | 谓词 | 来源 | 参与评分 |
|---|---|---|---|
| `self_shadow` | `cos_i ≤ 0` | Stage 7.0／7.2 已冻结 | 否 |
| `near_zero` | `0 < cos_i ≤ 0.1` | Stage 7.0／7.2 已冻结 | 否 |
| `mu_band_low` | `0.1 < cos_i ≤ 0.4` | 本子协议 | 是 |
| `mu_band_mid` | `0.4 < cos_i ≤ 0.7` | 本子协议 | 是 |
| `mu_band_high` | `0.7 < cos_i ≤ 1.0` | 本子协议 | 是 |

**边界包含规则**：除 `self_shadow` 为 `≤ 0` 外，一律**左开右闭**。

**互斥/穷尽**：五者两两互斥，并集穷尽 `cos_i` 的理论定义域 `[-1, 1]`。执行时必须逐
acquisition 断言该划分成立，不成立即停机。

### 分箱边界与段数的依据

- **下界 0.1**：Stage 7.0 `baseline_spec` 冻结的 `supported := cos_i > 0.1`，非本子协议新增。
- **上界 1.0**：`cos_i` 的理论上界。
- **均匀三等分**：`(0.1, 1.0]` 区间长 0.9，三等分得 0.3 一段，边界落在 0.4 与 0.7。
- **段数 = 3 的依据**：在「保留梯度可见性」与「维持每箱样本量」之间的最简折中。
  **这是结构性选择，不是物理推导**；均匀切分本身唯一，段数是其唯一自由度。

段数与边界一经冻结，**不得因 residual、risk proxy 结果或任何分箱样本量调整**。若将来
证据表明需要不同粒度，须另立 v2 子协议并重新经所有者批准，且新粒度在 exposure audit
中按其确立时点标注。

## 3. 必须随每次使用一并出现的声明

> 分箱边界是对模型自变量 μ 定义域的均匀切分，**不主张任何物理分区含义**。由于 μ 同时
> 受太阳高度角与地形共同决定，**同一分箱在不同 acquisition 之间不可直接互比**——
> 例如 μ ∈ (0.1, 0.3] 在 order 1 占 lit 的 20.9%，在 order 10 仅占 1.4%，该差异主要
> 来自太阳高度角而非地形风险。

跨 acquisition 的分箱级比较若要进行，必须显式说明该比较混入了太阳几何差异，
**不得表述为「不同地形风险下的表现差异」**。

## 4. 未评估项（沿用 Stage 7.2 mconf 子协议 §3）

`cast_shadow`、`horizon_occlusion`、`disocclusion_boundary`、
`geometric_instability_boundary`、`view_angle_occlusion` 一律标记 **`not_evaluated`**。

本子协议的全部分层建立在 `cos_i` 之上，因此继承 Stage 7.2 的覆盖边界：
**只覆盖自阴影**。任何分箱都不代表「该处几何可见性已被完整评估」。

## 5. 本子协议不做的事

不定义 residual 指标、risk proxy、coverage 分母或阈值（分属 Stage 7.0 与 Stage 7.4
条款 5／6）；不读取任何 residual、alpha 或分数；不改变 ROI、grid、成员集合、split、
topology 或 Stage 7.2／7.3 的任何冻结件；不主张任何分箱具有物理意义。
