## 0. 立场、范围与诚实边界

山地遥感物理基座以世界坐标中的物理状态为中心：图像外观是证据，不是最终表征；物理一致性高于纹理一致性。架构的目标是在复杂地形、几何畸变和异质光照下，形成可追溯、可迁移并带有不确定性的规范物理状态估计。

这不是“用极简可微模型取代一切传统处理”的主张。大气散射、多模态观测、时间先验和工程算力都仍是实际约束。架构的主张是：把不可回避的物理放进由真实观测约束的联合闭环，并按变化速率与依赖关系管理自由度，以便把误差来源、不确定性和失效边界显式暴露出来。

本文件不把仍未验证的机制写成结论。特别是 Stage 6.5.3-B 仅是当前机制级压力测试：它不能验证完整 L0-L5 架构；三种方法、mask、residual baseline、reliability 与 risk-coverage 的定义都属于独立节点实验合同，不由本文件猜测或补齐。

## 1. 设计原则

### 1.1 三个优先级

- **世界优先于图像：** 基元是世界坐标下的位置与观测关系，而不是孤立像素。
- **状态优先于外观：** 系统估计的是有物理语义、来源和不确定性的状态；外观只作为证据进入推断。
- **物理一致性优先于纹理一致性：** 训练与评估应检验状态经正向观测模型能否解释观测，而不是只追求视觉重建。

### 1.2 证据优先与未决义务

> 通过 QA、配准、定标与不确定性校验的有效观测，高于统计先验；观测自身不可信或模型解释不足时，系统必须保持未决，不得强行听从任何一方。

因此 L4 统计过程模型只能提供可追溯的软先验或初始化，不能伪装成当期观测反演。系统也不得为了输出完整图面而把无支持区域涂成确定结果。

### 1.3 阻力最小路径与多解陷阱

当多种物理解释可以同等拟合观测时，优化会偏向代价最低而非物理正确的解释。这一“阻力最小路径”是贯穿各层的审查规则：每次新增状态、传感器、先验或损失项，都必须说明其可能制造的等价替代、隔离机制与可证伪检验。

不允许以空间平滑掩盖状态边界，也不允许未经物理约束的跨模态学习直接改写物理状态定义。几何、可见性、辐射与状态之间的依赖必须可追溯。

## 2. 规范状态与 L0-L5 分层

“真值”在本架构中不是对模型内部状态的泛称。除独立地面测量外，L0/L1 输出一律称为**带不确定性的规范物理状态估计**；独立地面测量才可称为真值或参考真值。

### 2.1 状态层：G、X(t)、Z(t)、N(t)

- **G：稳定几何底座及其几何不确定性。** 它提供世界坐标、地形与长期稳定结构的规范表示；常态训练中锁定，不作为任意梯度吸收器。
- **X(t)：目标时变地表状态。** 例如含水量、植被覆盖度（VCF）及其他经实验合同定义的时变状态；它们可随时间被有效观测约束而更新。
- **Z(t)：独立观测得到的结构约束。** 例如 `canopy_height`；它与 G、X(t) 的来源、刷新节奏和不确定性分开记录，不能被悄悄折进某个状态项。
- **N(t)：干扰或标定变量。** 包括大气、辐射定标、反照率/BRDF 和传感器偏差等。N(t) 不得被错误归因给 G 或 X(t)。

DSM-DEM 的主要意义是提供冠层或地物高度约束，不是“粗糙度硬边界”。光学有效粗糙度与 SAR 尺度粗糙度必须分别定义；在没有独立证据前，它们仍是未决或受限变量，不能由 DSM-DEM 直接宣称为已锁定。

### 2.2 L0：世界坐标观测与几何底座

L0 以世界坐标位置、原始观测及其完整采集几何为核心。每条原始观测保留时间、传感器、太阳/视角、配准与来源信息；原始观测永久保留，不因派生状态失效而删除。

DEM、DSM、LiDAR、光学、多光谱、SAR/InSAR 及无人机多角度重建都可作为证据来源。无人机 SfM/MVS 或 AI 重建得到的点云、网格和纹理是 L0 观测来源之一，必须独立记录地面控制点/RTK 校正与重建质量，不能把重建缺陷混同为光照或遮挡问题。

### 2.3 L1：时变地表状态估计

L1 负责以 X(t) 为中心的时变状态估计，并消费 Z(t) 的独立结构约束与 N(t) 的标定/干扰解释。它不是把所有不一致都压入三个固定状态的容器，也不把状态估计误称为真值。

新增传感器若要影响状态，优先通过可审计的物理映射进入观测证据链。未经物理约束的 AI 翻译或重采样只能作为隔离的预处理候选，不能直接改变 L1/L2 的状态空间或梯度定义。

### 2.4 L2：几何与物理正向观测模型

L2 把 G、X(t)、Z(t)、N(t) 与采集几何组织成正向观测合成。本文档中“渲染”只指 L2 的正向观测合成；对几何变化的操作一律称为**局部几何重建/替换**，不再称为局部重渲染。

光学与 SAR 的可见性和失效机制分别建模。光学中的阴影、遮挡与辐射条件不能直接套用到 SAR 的叠掩、透视收缩和雷达阴影；SAR 专属的确定性屏障与可微正向算子仍是未决问题。

### 2.5 L3：受质量因子约束的自监督学习

L3 在可解释的有效支持范围内比较真实观测与 L2 合成观测，学习或更新受合同允许的状态。质量因子可以被编译为有效权重，但不能抹去其来源、作用时点或不确定性。零支持与模型不充分不是可被损失函数静默修复的噪声。

### 2.6 L4：时空过程模型

L4 按过程与时间尺度提供软先验、候选初始场或情景信息。L4 初始化必须标注来源和高不确定性，绝不伪装为已由观测反演出的结果；后续有效观测应能覆盖、修正或维持未决。

L4 的快慢变量冲突仍未解决：例如快速湿润事件与季节性先验相冲突时，系统尚无经过验证的判别阈值与恢复机制。

### 2.7 L5：下游适配与评测

L5 只在带来源和不确定性的规范状态估计上进行任务适配与评测。验证必须采用跨域断裂（Cross-Domain Isolated Validation）：训练区与留出区应在气候带、地质背景或植被类型上存在真实断裂，不能用同域随机切分替代外推检验。

## 3. 质量、支持与不确定性

质量不再由一个不可拆解的 Mconf 数字代表。每个输出及其有效权重必须保留至少下列可追溯因子：

- **support_mask：** 该位置是否具有可用于当前推断的观测支持。
- **geometry_visibility：** 给定几何与观测方向下的可见性、遮挡或阴影条件。
- **reconstruction_quality：** 几何重建本身的完整性、控制点校正、拼接与伪影风险。
- **sensor_quality：** 传感器、QA、噪声、饱和、云等观测质量信息。
- **model_adequacy：** 当前正向模型能否充分解释此处观测的诊断。
- **output_uncertainty：** 状态或产品输出的不确定性及其传播结果。

任务可在明确记录编译规则后从这些因子生成 `effective_weight`，但不得只保存该合成数值。各因子须可回溯到输入、算法版本、适用范围与时间。

所有输出必须标注为 `observed/inferred`、`prior_only` 或 `unsupported`。其中 `support_mask = 0` 或无合格观测支持时，只允许标为 `prior_only` 或 `unsupported`，不得标为 `observed/inferred`。

- **observed/inferred：** 有合格观测支持并经模型推断；
- **prior_only：** 仅由先验或初始化提供，保留来源与高不确定性；
- **unsupported：** 没有足以形成状态结论的支持。

无观测区与主动清零区必须分别量化。前者源于观测稀缺或不可获得；后者源于几何、质量或模型充分性判断主动拒绝使用观测。两者的覆盖率、外推误差与校准度不得混成一个“低置信度”总体数字。

## 4. 几何更新与依赖感知失效

几何变化不触发包围盒内历史状态的无条件全删。局部几何重建/替换应遵守以下边界：

- 原始观测永久保留，并保留其原始坐标/采集语义与来源。
- 受坐标映射、可见性或辐射关系变化影响的**派生状态**进入 `invalidated` 或 `quarantined`，并说明失效原因。
- 只对确实失效的派生状态重建；未受影响的状态不因空间邻近而被改写。
- 影响范围必须包含几何变化导致的可见性与辐射传播区域，而不只是几何包围盒。
- 不使用空间平滑掩盖新旧状态边界。边界的不确定性、来源和失效状态必须显式保留。

若 L4 为重建区域给出初始化，它仅能生成带 `prior_only` 来源与高不确定性的候选。它不得替代有效观测，也不得把初始化伪装成 L1 的观测反演历史。

## 5. 合成、渲染器与数据责任

Mitsuba/Eradiate 等高保真渲染器当前限定为**离线参考与合成数据源**。这是本项目基于遥感物理覆盖、算力和集成成熟度作出的工程裁决，不是对 Mitsuba 3 技术上是否可微的否定。只有经过专项可行性验证后，相关技术才可作为 L2 候选后端。

所有合成数据必须记录 simulator provenance、输入场景、参数版本、标签生成方式与 domain gap 说明。合成数据不得自动视为真实标签，也不得同时被当作训练来源和独立验证真值。独立验证仍需要与训练来源隔离的观测或地面参考。

## 6. 数据与验证策略

- 从地貌反差明显的小样区开始，逐步验证，而不以架构文字代替实验。
- 用独立地面测量、机载 LiDAR、GNSS 和可审计的参考观测来标定或验证；它们与模型状态估计的地位必须区分。
- 对无观测、主动清零、几何遮挡、重建低质量、持续大气遮挡等区域分层报告覆盖、误差和不确定性校准。
- 共享的是地形条件到物理状态的可学习关系，不是把一个区域的具体反照率或状态数值覆盖到另一区域。
- 任何“完整覆盖”产品都必须随输出来源类别、质量因子和不确定性一并交付。

## 7. 已知失效域与未决问题 A-I（不假装解决）

### A. 遮挡边界的信息缺口

主动拒绝不可信观测能阻止错误归因，却会形成信息缺口。需要量化其覆盖、成因、先验依赖和补观测可行性，而不是把清零当成问题已被解决。

### B. SAR 正向算子的可微化与专属可见性规则

SAR 的相干成像、斑点、介电特性以及叠掩/透视收缩/雷达阴影均不能直接沿用光学规则。可微化与独立质量机制仍是开放问题。

### C. 无观测区的外推幻觉

没有观测且缺少相似训练样本时，系统可能给出貌似合理但不受现实约束的结果。应以跨域断裂验证和来源类别使其可见，而非宣称消除。

### D. 多云区与持续观测稀缺

晴空稀缺是物理约束。补观测是否有效取决于传感器与云/遮挡成因，不能把光学补拍假设为普遍解法。

### E. 大尺度工程可落地性

联合闭环是否能在可接受算力、数据与运维成本下扩展，尚待实验验证。降低耦合复杂度不等于已经完成工程落地。

### F. 状态可辨识性与结构约束的边界

冠层/地物高度约束、X(t) 状态、光学有效粗糙度与 SAR 尺度粗糙度的独立定义、刷新节奏和可辨识性尚未关闭。DSM-DEM 不能替代这些独立证据。

### G. L4 快慢变量冲突

快速真实变化、传感器噪声与定标误差发生冲突时，何时接受观测、何时保持未决、如何恢复先验影响，尚无经验证的判定与评测协议。

### H. 局部几何重建/替换的触发与影响范围

如何区分持续几何变化与随机残差，如何界定包含可见性与辐射传播的影响范围，以及如何审查和回滚，仍需小样区经验与专项验证。

### I. 主动清零区的长期信息缺口

主动清零与被动无观测应分层量化。几何遮挡、重建质量、持续大气遮挡等不同来源的补观测路径、风险与评价口径仍待制定。

## 8. 推进约束

最小闭环应先验证可追溯的观测支持、质量因子、状态来源与不确定性，再扩大到多区域、多模态、L4 和下游任务。每一步只能声称其实际检验的机制，不可越级声称完成整套架构。

本版不创建 Stage 6.5.3-B 的配置、执行器、结果或报告，不运行任何实验，也不把该节点的未定方法写入架构正文。实验方法、mask、residual、reliability 与 risk-coverage 的精确定义必须在独立节点合同中经证据与裁决后形成。

## 9. 版本说明与出版纪律

v3 保留 v2 的世界坐标优先、状态优先、物理一致性、阻力最小路径警惕、L0-L5 分层、跨域断裂验证、L4 快慢变量冲突、无观测/主动清零区量化、无人机重建、质量分离、离线高保真合成数据源及未决问题 A-I。

相对 v2，v3 的实质修正是：以 G/X/Z/N 代替把误差压入三个 L1 状态；撤销 DSM-DEM 对粗糙度的硬边界主张；以六类可追溯质量因子取代单一 Mconf；明确 `observed/inferred`、`prior_only`、`unsupported` 来源类别；采用依赖感知的失效与隔离，而不是包围盒全清；并将渲染器、合成数据和 Stage 6.5.3-B 的主张收紧到其真实证据边界。
